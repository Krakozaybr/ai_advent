# AI Advent Web

Локальное учебное веб-приложение с десятью последовательными экспериментами:
от первого запроса к LLM до стратегий управления контекстом агента.

## Запуск

```bash
npm install
npm run dev
```

После запуска открой <http://127.0.0.1:3000>.

## OpenRouter

Открой «Настройки» в интерфейсе и сохрани API-ключ. Он попадёт в локальный
`data/settings.json`; папка `data` исключена из Git, а сам ключ не возвращается
в браузер. Если в корне уже есть `.env` с `OPENROUTER_API_KEY`, приложение
подхватит его автоматически.

## Текущее состояние

Готов День 1: пользователь вводит запрос, выбирает модель OpenRouter, получает
ответ и может скачать результат в JSON. По умолчанию используется дешёвая
instruct-модель `qwen/qwen3-30b-a3b-instruct-2507`.

Сохранённая CLI-версия Days 1–5 находится в
[`legacy/cli-days-1-5`](legacy/cli-days-1-5/README.md).
