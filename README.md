# AI Advent

## Day 1 — запрос к LLM через локальный Codex app-server

Минимальный CLI запускает локальный Codex app-server, отправляет ему текст и
печатает ответ. Он использует текущий вход Codex: API-ключ в проекте не нужен.

### Запуск

```bash
npm run ask -- "Объясни, что такое LLM в одном предложении"
```

Перед запуском должны быть установлены Codex CLI и выполнен вход:

```bash
codex login
```

Можно выбрать доступную в Codex модель на один запрос:

```bash
CODEX_MODEL="gpt-5.6-luna" npm run ask -- "Придумай короткий тост"
```

`app-server` — экспериментальный локальный интерфейс Codex. Скрипт создаёт
временный поток и запрашивает режим без доступа к окружению.

## Days 2–5 — эксперименты через OpenRouter

Для контролируемых параметров генерации и сравнения разных моделей дни 2–5
используют OpenRouter напрямую. Создай API key в OpenRouter и выбери один
конкретный ID модели из их каталога — не `openrouter/free`, так как он выбирает
модель случайно.

```bash
export OPENROUTER_API_KEY="ваш_ключ"
export OPENROUTER_MODEL="provider/model"
node day2/app.mjs
```

Скрипт напечатает оба ответа и запишет подробный результат в `day2/result.json`.
Этот файл игнорируется Git, чтобы результаты каждого запуска не смешивались с
исходным кодом.
