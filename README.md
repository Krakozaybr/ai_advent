# AI Advent

## Day 1 — запрос к LLM через локальный Codex app-server

Минимальный CLI запускает локальный Codex app-server, отправляет ему текст и
печатает ответ. Он использует текущий вход Codex: API-ключ в проекте не нужен.

### Запуск

```bash
npm run ask -- "Объясни, что такое LLM в одном предложении"
```

Перед запуском должны быть установлены Codex CLI и выполнен вход:

```bash
codex login
```

Можно выбрать доступную в Codex модель на один запрос:

```bash
CODEX_MODEL="gpt-5.6-luna" npm run ask -- "Придумай короткий тост"
```

`app-server` — экспериментальный локальный интерфейс Codex. Скрипт создаёт
временный поток и запрашивает режим без доступа к окружению.

## Days 2–3 — эксперименты через локальный Codex app-server

Days 2–3 используют текущий вход Codex, поэтому OpenRouter-ключ и `.env` не
нужны. Перед запуском выполни `codex login`, затем запускай команды из корня
проекта. Каждый скрипт печатает результат и сохраняет полный JSON в папке
своего дня.

### Day 2 — формат, длина и завершение ответа

```bash
npm run day2
```

В консоли: один ответ без ограничений и один с форматом, лимитом длины и
инструкцией `END`. Файл результата: `day2/result.json`.

### Day 3

```bash
npm run day3
```

Скрипт решает одну логическую задачу четырьмя способами и сохраняет ответы,
сгенерированный prompt и проверку правильного числа в `day3/result.json`.

## Day 4 — эксперимент через OpenRouter

Для Day 4 один раз создай `.env` и вставь бесплатный или платный ключ
OpenRouter и конкретный ID модели:

```bash
cp .env.example .env
```

`.env` уже исключён из Git. Не используй `openrouter/free`: он выбирает модель
случайно и портит сравнение.

### Day 4 — температура

```bash
npm run day4
```

Один творческий prompt запускается с `temperature` 0, 0.7 и 1.2. В
`day4/result.json` сохраняются ответы, соблюдение ограничений и простые метрики
разнообразия; качественный вывод делается по самим текстам.

## Day 5 — сравнение моделей Codex

Day 5 не требует `.env`: он сравнивает модели Codex `gpt-5.6-luna`,
`gpt-5.6-terra` и `gpt-5.6-sol` на одном запросе.

```bash
npm run day5
```

Скрипт выводит время, ответы и проверку правильного числа, а также сохраняет
результаты в `day5/result.json`. Codex app-server не возвращает токены и
стоимость: эти поля в результате отмечены как `н/д`.
