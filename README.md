# AI Advent

## Day 1 — запрос к LLM через API

Минимальный CLI отправляет текст в OpenAI Responses API и печатает ответ.

### Запуск

```bash
export OPENAI_API_KEY="ваш_ключ"
npm run ask -- "Объясни, что такое LLM в одном предложении"
```

По умолчанию используется `gpt-5-mini`. Чтобы выбрать другую доступную модель:

```bash
OPENAI_MODEL="gpt-5" npm run ask -- "Придумай короткий тост"
```

Ключ не записывается в репозиторий: он читается только из переменной окружения.
