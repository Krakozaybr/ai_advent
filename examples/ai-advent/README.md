# Готовые доски 1–9

JSON-файлы в `boards/` — внешний seed-набор. Код платформы v3 не зависит от
этих примеров. Для пересборки файлов после редактирования сценариев:

```sh
node examples/ai-advent/build-seed-pack.mjs
```

Запусти локальный backend v3 и импортируй все доски:

```sh
node examples/ai-advent/import.mjs
```

По умолчанию используется `http://127.0.0.1:3001`; адрес можно задать через
`BOARD_API_URL`. Чтобы импортировать один файл, передай его имя:

```sh
node examples/ai-advent/import.mjs board-05.json
```

Повторный импорт того же `externalId` сохраняет доску без перезаписи истории.
Для дней 2, 3 и 6 заготовки assistant явно помечены как демонстрационные.
Снимок цен в сценарии 5 получен 2026-09-27; проверь актуальную карточку модели
перед отправкой запроса. В seed нет ключей, токенов или ID provider threads.
