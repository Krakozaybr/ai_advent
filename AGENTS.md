# AI Advent Web

## Назначение

- Локальное учебное React/Express-приложение с отдельной вкладкой для каждого дня.
- Облачные LLM-запросы идут через сервер и OpenRouter; API-ключ не передаётся
  в браузер. Дни 26–28 в v3 используют локальный Ollama без облачного fallback.
- Состояние учебных агентов хранится в `data/agent.sqlite`; `data/` не коммитится.

## Команды

- `npm run dev` — локальная разработка на `http://127.0.0.1:3000`.
- `npm test` — серверные и вспомогательные тесты.
- `npm run build` — production-сборка интерфейса.
- `npm run local:serve`, `local:pull` — локальный Ollama и скачивание моделей.
- `npm run local:backend`, `local:web` — сервер и интерфейс локальных дней v3.
- `npm run local -- index|probe|benchmark` — локальный индекс и реальные проверки;
  только явный `benchmark --cloud` разрешает облачное сравнение.

Перед завершением изменения запусти `npm test`, `npm run build` и
`git diff --check`.

## Структура

- `src/DayN.jsx` — интерфейс и учебный сценарий конкретного дня.
- `shared/dayN.js` — общие константы, дефолтные данные и правила домена.
- `server/dayN.mjs` — логика агента, если день вызывает LLM.
- `server/*-store.mjs` — отдельные SQLite-хранилища состояния.
- `server/memory-mcp-server.mjs` — локальные MCP-инструменты памяти через `stdio`.
- `server/memory-mcp-client.mjs` — MCP-клиент и перевод схем инструментов в формат OpenRouter.
- `server/app.mjs` — HTTP-маршруты и валидация входных данных.
- `test/server.test.mjs` — интеграционные проверки API с подменённым LLM.
- `server/ollama.mjs` и `examples/ai-advent/local-llm.mjs` — общий локальный
  клиент и RAG для CLI и веба; `LocalLlmRoutes.kt` связывает их с сервером v3.
- `v3/frontend/src/LocalDays.tsx` — отдельные экраны `?localDay=26|27|28`;
  обычные ленты доски не являются локальным чат-провайдером.

## Добавление дня

1. Добавь общие данные и серверную логику.
2. Подключи маршруты в `server/app.mjs`; секреты разрешай только на сервере.
3. Добавь `src/DayN.jsx`, запись в `src/days.js` и компонент в `src/App.jsx`.
4. Обнови число вкладок в `src/styles.css` и описание в `README.md`.
5. Добавь интеграционный тест без реального запроса к OpenRouter.

## Ограничения

- Не записывай API-ключи, `.env`, SQLite-файлы и результаты запросов в Git.
- Не показывай скрытые рассуждения модели; показывай входные данные, публичные
  проверки, HTTP-параметры, метрики и итоговый ответ.
- Детерминированные правила состояния и безопасности проверяй кодом до LLM.
- MCP-инструменты выполняет сервер приложения: модель только возвращает
  `tool_calls`. Не открывай модели инструменты удаления или очистки памяти.
- Сохраняй ответы вкладок при переключении: React-компоненты остаются
  смонтированными и скрываются через `hidden`.
- Для Markdown используй общий `MarkdownContent`, включая GFM и формулы.
- Локальные и облачные эмбеддинги не смешивай: локальный индекс хранится
  отдельно в `v3/data/rag/classics-ollama/`. Веса, индексы и отчёты не коммить.
