# Интерактивный макет v3

Открой `index.html` в браузере. Backend, ключи и установка пакетов не нужны.
Макет не отправляет запросы к модели и не меняет данные рабочего приложения.

В нём можно переключать доски, двигать независимые ленты, создавать ветки и
клоны, менять ширину лент, открывать детали ответа и настройки сессии.
Двойной щелчок по названию ленты включает редактирование. В поле ввода `Enter`
добавляет корректировку, `Shift+Enter` — задачу в очередь. Это демонстрация
состояний интерфейса, без настоящего ответа LLM.

В свободном режиме колесо двигает камеру по вертикали, `Cmd`/`Ctrl` + колесо
меняет масштаб, средняя кнопка мыши двигает камеру в обе стороны. В фиксированном
режиме выбранная лента центрируется по горизонтали; положение камеры каждой
доски сохраняется при переключении вкладок. Обновление страницы сбрасывает
макет к исходному виду.
