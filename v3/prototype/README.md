# Интерактивный макет v3

Открой `index.html` в браузере. Backend, ключи и установка пакетов не нужны.
Макет не отправляет запросы к модели и не меняет данные рабочего приложения.

На экране Home можно создать, открыть, закрыть, архивировать, восстановить или
удалить доску; архивные доски вынесены в отдельный раздел. Во вкладке
«Сабагенты» показана родительская сессия: активный
сабагент виден всегда, а завершённые появляются после закрепления в диалоге
настроек и раскрытия линии у родительской сессии. Цвет фона группы меняется
через квадрат в заголовке родительской сессии: выбор сразу виден на доске,
«Отмена» возвращает прежний цвет, «Применить» сохраняет новый до обновления страницы.

В макете можно переключать доски, перетаскивать независимые сессии вместе с ветками,
создавать ветки и клоны, менять ширину сессий перетаскиванием разделителей,
добавлять сессии по краям доски и между независимыми группами, открывать детали
ответа, архивировать и удалять сессии. В деталях ответа показаны форматированный
запрос, демонстрационные вызовы инструментов и краткое публичное описание работы;
скрытые рассуждения модели не показываются. Новая сессия начинается с выбора
Codex или OpenRouter. Модель и уровень рассуждения Codex выбираются в общем
виджете под полем ввода, а молния переключает обычную и быструю скорость.
Температура OpenRouter — в расширенных настройках сессии.
AGENTS.md (или системный промпт OpenRouter), скиллы и MCP — на отдельных
вкладках настроек сессии. В списках скиллов, MCP и архиве есть поиск.
Инструменты каждого MCP раскрываются отдельно.
Двойной щелчок по названию сессии включает редактирование. В поле ввода `Enter`
добавляет корректировку, `Shift+Enter` — задачу в очередь. Это демонстрация
состояний интерфейса, без настоящего ответа LLM.

В свободном режиме колесо плавно двигает камеру по вертикали, горизонтальная
прокрутка тачпада — по горизонтали, `Cmd`/`Ctrl` + колесо меняет масштаб,
средняя кнопка мыши двигает камеру в обе стороны. В фиксированном
режиме выбранная сессия центрируется по горизонтали; положение камеры каждой
доски сохраняется при переключении вкладок. Обновление страницы сбрасывает
макет к исходному виду.
