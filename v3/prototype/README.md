# Интерактивный макет v3

Открой `index.html` в браузере. Backend, ключи и установка пакетов не нужны.
Макет не отправляет запросы к модели и не меняет данные рабочего приложения.

В нём можно переключать доски, перетаскивать независимые сессии вместе с ветками, создавать ветки и
клоны, менять ширину сессий, открывать детали ответа, архивировать и удалять
сессии. Модель, подтверждение, effort и скорость меняются рядом с полем ввода;
AGENTS.md, скиллы и MCP — на отдельных вкладках окна настроек сессии. В списках
скиллов и MCP есть поиск, а инструменты каждого MCP раскрываются отдельно.
Двойной щелчок по названию сессии включает редактирование. В поле ввода `Enter`
добавляет корректировку, `Shift+Enter` — задачу в очередь. Это демонстрация
состояний интерфейса, без настоящего ответа LLM.

В свободном режиме колесо двигает камеру по вертикали, `Cmd`/`Ctrl` + колесо
меняет масштаб, средняя кнопка мыши двигает камеру в обе стороны. В фиксированном
режиме выбранная сессия центрируется по горизонтали; положение камеры каждой
доски сохраняется при переключении вкладок. Обновление страницы сбрасывает
макет к исходному виду.
